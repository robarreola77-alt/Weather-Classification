# Weather-Classification
Rainfall Prediction Classifier built with custom feature engineering and grid search optimization. Implements full pipeline evaluation using cross-validation and multiple performance metrics (ROC-AUC, F1-Score, Confusion Matrix) to bridge statistical rigor with production-ready Machine Learning.

Research to Production Note: While this repository evaluates traditional classifiers using scikit-learn, this pipeline can be scaled in production environments using MLOps frameworks (like MLflow) and integrated with streaming data pipelines for real-time weather forecasting.
